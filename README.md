# 糖的多重宇宙・故事創作室 v2

一份完整作品包含共同說明、共同人物與關係、三個章節。每章預設三幕、三個結局及三個空白選項，內容以獨立寫作提示引導。預設可收合的樹狀分支；教師安排接線與派發，學生點卡片共編。不同單位採不同欄位，大型編輯頁每60秒背景儲存，底部儲存列常駐。議事庭紀錄先存為參考素材，再選擇放入的章節與幕次，不會自動填入名稱、劇情或選項。

GitHub Pages 僅提供介面。帳號、固定密碼、作品與版本紀錄保留在 Google 試算表，圖片保留在 Drive，不寫入儲存庫。

未核對的史料、等待接線的選項、缺少幕數或結局，會在發布時列出。教師可標記少量路線為提前結局。
