# 糖的多重宇宙・故事創作室 v2

一份完整作品包含共同說明、共同人物與關係、三個章節。教師在地圖安排卡片、拖曳接線、派發工作，學生在同一卡片編寫情境、上傳圖片、設計選項結果與真實對照卡。

GitHub Pages 僅提供介面。帳號、固定密碼、作品與版本紀錄保留在 Google 試算表，圖片保留在 Drive，不寫入儲存庫。

## 後台更新

必須更新 GAS 至 v2 的完整 Code.gs。保留 Bridge.html 與既有指令碼屬性。v2 已包含連線初始化修正，不依賴註解標記。登入後若是舊格式，教師可按「保留原內容，轉成三章作品」。原內容放第一章，新增第二、三章，不改動已發布版本。

GAS 的 STUDIO_FRONTEND_URL 保持 https://peitt1940-creator.github.io/multiplestories-suger/ 。config.js 只放公開 /exec 網址。前端使用原生 HTML/CSS/JavaScript，無須編譯。

未核對的史料、等待接線的選項、缺少幕數或結局，會在發布時列出。教師可標記少量路線為提前結局。
